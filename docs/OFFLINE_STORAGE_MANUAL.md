# دليل التشغيل والتخزين بدون إنترنت (CourseViewer Offline Storage & Download Manager)

يوثق هذا الدليل المعمارية الفنية ودليل المستخدم لكيفية تحميل وتخزين الدروس التفاعلية للغرف الصفية (`Classroom Viewer`) وتشغيلها بدون اتصال بالإنترنت (`Offline Mode`) عبر متصفحات الحاسوب والهواتف الذكية.

---

## 1. المعمارية الفنية (Technical Architecture)

يعتمد نظام التشغيل بدون إنترنت على محرك تخزين محلي هجين متوافق مع كافة المتصفحات الحديثة وتطبيقات الهواتف المحمولة (WebView / Capacitor):

```mermaid
flowchart TD
    User([المستخدم: طالب / معلم]) --> UI[ClassroomPlayerPage]
    UI --> Resolver[Offline Resolver]

    subgraph ClientStorage [ذاكرة جهاز العميل (Browser & Mobile Storage)]
        IDB[(IndexedDB: CourseViewerLocalDB)]
        MediaCache[(CacheStorage: courseviewer-media-v1)]
    end

    Resolver -->|1. التحقق من وجود الدرس محلياً| IDB
    Resolver -->|2. استعادة ملفات الصوت والصور| MediaCache

    IDB -->|وجِد الدرس محلياً| Hydrate[توليد In-Memory Blob URLs]
    Hydrate -->|تشغيل فوري بدون شبكة| Canvas[@openmaic/viewer Player]

    Resolver -->|غير مخزن محلياً| RemoteFetch[جلب الدرس من Cloudflare R2 / Worker]
    RemoteFetch --> Canvas

    UI --> Downloader[Web Worker: downloader.worker.ts]
    Downloader -->|تنزيل حزمة .zip في الخلفية| R2[خوادم R2]
    Downloader -->|فك الضغط وحفظ JSON| IDB
    Downloader -->|حفظ ملفات الصوت والصور| MediaCache
```

### طبقات التخزين:
1. **قاعدة بيانات المفهرس (`IndexedDB: CourseViewerLocalDB`)**:
   - مخزن `lessons`: يحفظ هيكل بيانات الدرس (`manifest.json` أو `classroom.json`) متضمناً المشاهد، الشرائح، الألواح البيضاء، نصوص الحوارات، وحالة الإكمال.
   - مخزن `units`: فهرسة شاملة للوحدات الدراسية وعدد الدروس المحملة.
   - مخزن `download_queue`: إدارة طابور التنزيل ومتابعة نسبة الإنجاز والسرعة.
2. **مخزن وسائط الكاش (`CacheStorage: courseviewer-media-v1`)**:
   - يحفظ الملفات الثنائية الكبيرة (`.mp3` لأصوات المعلم الذكي TTS، الصور البصرية `.webp`, `.png`, الفيديوهات، وملفات SVG).
   - يتم تخزين كل ملف تحت المفتاح المرجعي Canonical URL (مثل `/classroom-media/${classroomId}/media/${filename}`).
3. **عامل الخلفية المستقل (`Web Worker: downloader.worker.ts`)**:
   - يعمل في Thread منفصل عن واجهة المستخدم، مما يضمن استمرار تشغيل الصوت والرسوم المتحركة دون أي تقطيع أثناء تنزيل دروس أخرى في الخلفية.

---

## 2. ميزات التشغيل بدون إنترنت

- **أولوية التشغيل المحلي (Offline-First)**:
  عند فتح أي درس، يتحقق المشغل أولاً من ذاكرة الجهاز. إذا وُجد الدرس كاملاً، يتم تشغيله فوراً وبدون إرسال أي طلب شبكة لخوادم R2.
- **التوافق التام مع النظام الحالي (100% Backward Compatible)**:
  إذا لم يكن الدرس محملاً، يتدفق التحميل تلقائياً إلى مسارات R2 و Cloudflare Pages الحالية دون أي تغيير في السلوك.
- **الحفظ الدائم (Persistent Storage)**:
  يطلب النظام تلقائياً من المتصفح تفعيل ميزة `navigator.storage.persist()` لمنع حذف الدروس تلقائياً عند امتلاء مساحة القرص.

## 3. دليل الاستخدام (User Guide)

### أ. تنزيل درس وغرفة صفية للتشغيل بدون إنترنت:
1. افتح الدرس المراد تنزيله في المشغل (`ClassroomPlayerPage` أو `PrintedPagesViewer`).
2. انقر على أيقونة **تنزيل** (<kbd>📥</kbd>) في شريط التحكم.
3. تفتح نافذة **"مدير التنزيلات والتشغيل بدون إنترنت"**.
4. يظهر خياران محددين افتراضياً ("تنزيل الكل"):
   - `[✓]` **الغرفة الصفية التفاعلية للدرس (Classroom & Audio)**: المشاهد، الحوارات، وأصوات TTS.
   - `[✓]` **صفحات الكتاب المطبوع (دقة 900px WebP)**: صور الصفحات الممسوحة المحسنة بدقة 900px فقط.
5. يمكن للمستخدم إبقاء التحديد لتنزيل الكل معاً، أو إلغاء تحديد أي عنصر لتنزيل ما يحتاجه فقط.
6. اضغط على زر **"تنزيل الكل الآن"** (أو **"تنزيل المحدد الآن"**).
7. ستشاهد شريط تقدم التنزيل بنسبة مئوية حية ورقم الصفحة المحملة.
8. بمجرد اكتمال التنزيل، ستظهر شارة خضراء تفيد بالحفظ المحلي، مع إمكانية حذف أي جزء بصورة منفصلة لتحرير المساحة.

### ب. قراءة وتصفح صفحات الكتاب بدون إنترنت (`PrintedPagesViewer`):
1. عند تشغيل الدرس بدون شبكة، يتحقق المشغل من وجود صور 900px في الكاش المحلي.
2. تُعرض الصفحات فوراً من الذاكرة المحلية كعناصر Blob سريعة.
3. تظهر شارة خضراء في الشريط العلوي: **`💾 محلي (أوفلاين)`**.
4. **على الهواتف المحمولة**:
   - التمرير بالسحب (Touch Swipe Left/Right) لتقليب الصفحات يميناً ويساراً بسلاسة في العرض الأفقي.
   - إخفاء الشريط العلوي تلقائياً بعد 3 ثوانٍ من عدم اللمس، واستعادته فور لمس الشاشة.
1. افتح أدوات المطور في المتصفح بالضغط على <kbd>F12</kbd> أو <kbd>Ctrl+Shift+I</kbd>.
2. انتقل إلى تبويب **Network** (الشبكة).
3. غيّر سرعة الاتصال من **No Throttling** إلى **Offline**.
4. أعد تحديث الصفحة أو افتح الدرس الذي قمت بتنزيله سابقاً.
5. **النتيجة**:
   - يفتح الدرس فوراً دون اتصال بالإنترنت.
   - تظهر شارة خضراء في شريط التحكم: **`💾 محلي (أوفلاين)`**.
   - تعمل جميع المشاهد والرسومات والصوت التفاعلي بالكامل من الذاكرة المحلية.

### ج. حذف درس من الذاكرة المحلية لتحرير المساحة:
1. افتح نافذة مدير التنزيلات عبر أيقونة التنزيل.
2. اضغط على زر **"حذف من الذاكرة"** المقترن بالدرس.
3. يتم إخلاء المساحة فوراً من كلٍ من `IndexedDB` و `CacheStorage`.

---

## 4. سعات التخزين والحدود المسموحة (Storage Limits)

- **متصفح Chrome / Edge وأجهزة أندرويد**:
  يمنح المتصفح للموقع سعة تصل إلى **60% من المساحة الخالية على القرص**. على سبيل المثال، إذا كان بهاتفك 10 جيجابايت مساحة فارغة، يمكنك تخزين حتى 6 جيجابايت (ما يقارب 400 إلى 1,000 درس تفاعلي كامل).
- **أجهزة آبل (iOS / Safari)**:
  تدعم حتى عدة جيجابايت في وضع ملء الشاشة أو عند إضافة الموقع إلى الشاشة الرئيسية (PWA).

## 5. الأوامر البرمجية للمطورين (Developer Reference)

### التحقق من وجود الدرس محلياً:
```typescript
import { checkLocalClassroom } from '@/lib/storage/offline-resolver';

const localResult = await checkLocalClassroom('bio10p1', 'u1', 'l1', 'bio_u1_l1_01');
if (localResult) {
  console.log('Classroom is cached offline:', localResult.data);
}
```

### استخدام خطاف إدارة التنزيلات في React:
```tsx
import { useDownloadManager } from '@/hooks/useDownloadManager';

function MyComponent() {
  const { downloadLesson, deleteLesson, storageStats } = useDownloadManager();

  const handleDownload = () => {
    downloadLesson({
      subject: 'bio10p1',
      unit: 'u1',
      lesson: 'l1',
      classroomId: 'bio_u1_l1_01',
      title: 'الخلية الحية',
    });
  };

  return <button onClick={handleDownload}>تحميل الدرس</button>;
}
```
